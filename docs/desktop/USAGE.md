# Windows 候选版使用说明

该候选包还未完成干净机器及真实平台验收，验收边界见 TEST-REPORT.md。

安装 `Concourse Setup 0.1.0.exe` 后启动，先选择全新开始或导入旧项目目录。导入前完全退出旧服务；目标已有业务库时拒绝合并。首次引导询问开机静默启动与关闭窗口后是否继续运行，可在托盘菜单调整。

在“抓取器”页面展开各平台配置：学者网填写账号密码与数字课程 ID；iTest 填写账号密码；Moodle 保存私人 HTTPS 日历订阅地址并验证连接；Codeforces 公共赛事无需账号。保存不会自动启用，确认配置后再启用定时抓取。

需要人工验证时主动选择“打开辅助登录”，在浏览器中完成后点击“已完成登录”；可取消，超时 3 分钟后释放。凭据由 Windows 当前用户 DPAPI 加密，查询不返回秘密。

系统提醒默认提前 1440/60 分钟。比赛、考试按开始时间，作业按截止时间；全天事项当地 09:00。完成/提交、删除、停用平台不再提醒。首次启用和设置变更建立基线，避免大量历史提醒；重启或唤醒最多补最近 24 小时，同事项合并。投递确认崩溃窗口可能重复通知。

数据默认保存在 `%LOCALAPPDATA%\Concourse`，卸载保留数据。不要手动覆盖或合并运行中的数据库。升级失败请参考 RECOVERY.md，保留唯一原始备份。

开发与验收：必须指定绝对 `CONCOURSE_DATA_DIR`，候选版使用覆盖目录时不会改动开机启动注册项。源码运行默认 `.desktop-data`；Python pytest 在导入应用前自动建立临时目录。
